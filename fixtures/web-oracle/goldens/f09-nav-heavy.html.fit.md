
    # Settings Overview

    Preferences are grouped into profiles. Each profile controls defaults for sessions, appearance, and notifications.

    ## Session defaults

    Sessions expire after 30 days of inactivity unless renewed. Renewal resets the window without changing tokens.

    - **Timeout:** 30 days
- **Renewal:** automatic on activity
- **Revocation:** immediate on password change

    ## Appearance

    Themes are stored per profile. Dark mode follows the system setting by default.

    ## Notifications

    Email digests are sent weekly. Critical alerts bypass the digest and send immediately.

    | Event | Email | Push |
| --- | --- | --- |
| Digest | yes | no |
| Critical alert | yes | yes |
