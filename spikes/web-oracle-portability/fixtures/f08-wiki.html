Pipe (Unix)

In Unix and Unix-like systems, a pipe is a unidirectional data channel between processes. Pipes were among the original features of Unix and remain a core composition primitive.

Creation

Pipes are created with the pipe system call, which returns a pair of file descriptors. One end is for reading, the other for writing.

Anonymous pipes

Anonymous pipes exist only as file descriptors and cannot be addressed by name. They form the basis of pipelines where the output of one command feeds the input of the next.
